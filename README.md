# Sanket Sharma — ApexPlanet Internship Task 2

A dark, modern, responsive front-end project featuring a validated contact form and a dynamic task board.

## Features
- Contact form with required-field, email-format, consent, and message-length validation.
- Dark UI with bright mint, violet, and orange accents.
- Responsive layout built using Flexbox, CSS Grid, and media queries.
- Mobile navigation menu.
- Dynamic task board: add, complete, delete, filter, and clear completed tasks.
- Priority labels, progress bar, and localStorage persistence.
- Accessible labels and validation/status messages.

## Run locally
1. Extract `Sanket_ApexPlanet_Task2.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to open it in Chrome, Edge, or Firefox.
4. No Node.js, installation, or server is needed.

## Files
- `index.html` — structure and page content
- `style.css` — dark theme and responsive styling
- `script.js` — validation, navigation, and task-board behaviour

## Important
The contact form performs front-end validation only; it does not send emails or submit data to a server. Tasks are stored in the browser's localStorage on the same device.

## Technologies
HTML5 · CSS3 · JavaScript · DOM manipulation · Events · Validation · localStorage
